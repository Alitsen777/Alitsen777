## 🚀 Featured Project

### 📈 ETF Cash-Flow Manager & Automated Alert System
*ETF 現金流管理與自動化預警系統*

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)
![Make.com](https://img.shields.io/badge/Make.com_RPA-6D00CC?style=flat-square&logo=make&logoColor=white)
![Codex](https://img.shields.io/badge/AI--assisted-Codex-412991?style=flat-square&logo=openai&logoColor=white)

A web app that helps investors see their ETF dividend cash flow for the next 12 months and get automatic price alerts.

- **Interactive dashboard** — Try it without logging in. 50 built-in ETFs with filters and custom additions; 12-month dividend cash flow is aggregated and visualized in real time.
- **Accounts & data storage** — User authentication with session-state management; users can save their holdings and avatar to the cloud.
- **Automated price alerts (RPA)** — Scheduled Make.com workflows compare prices at market open and close every day and email alerts, while keeping API usage and credentials under control.
- **AI-assisted development** — Used Codex to speed up the Python logic and MVP interface; did the functional testing and debugging myself.
